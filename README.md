# Beginner Web Development Projects

A collection of projects I’ve built while learning web development. These projects give me practice with HTML, CSS, and JavaScript, from designing web pages to building a simple interactive game.

## Projects

| Project | Description | Technologies |
| --- | --- | --- |
| [E-commerce website](./E-commerce%20website%20/) | A clothing shop interface with a homepage and product detail page. The homepage uses Tailwind CSS. | HTML, Tailwind CSS |
| [Profile Card](./Profile%20Card/) | A profile card page with a photo, name, and profile details. | HTML, CSS |
| [Restaurant Landing Page](./Restaurant%20Landing%20Page/) | A landing page for a restaurant, with sections for its brand, food, and contact information. | HTML, CSS |
| [SnakeGame](./SnakeGame/) | A Snake game rendered on a canvas, with separate files for drawing, input, and game logic. | HTML, CSS, JavaScript |
| [UltraEdit Clone](./UltraEdit%20Clone/) | A practice recreation of the UltraEdit website’s landing page. | HTML, CSS |

## What I’m Learning

- Structuring web pages with HTML
- Styling layouts and components with CSS
- Using Tailwind CSS to build page styles
- Adding interaction and game logic with JavaScript
- Organizing projects into files and folders

## Running the Projects

Most projects can be opened by launching their `index.html` file in a browser.

For the e-commerce homepage, install its dependencies and start the Tailwind CSS watcher from the `Home Page` folder:

```bash
npm install
npm run dev
```

Then open `index.html` in a browser.
