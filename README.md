# Beginner Full-Stack Web Development Projects

A collection of beginner projects built while learning web development. The projects cover page layout and styling, a Tailwind CSS storefront, and a JavaScript canvas game. This repository will grow as I learn more about front-end and back-end development.

## Projects

| Project | Description | Technologies |
| --- | --- | --- |
| [E-commerce Website](./E-commerce%20website%20/) | Clothing store homepage and product detail page. The homepage uses Tailwind CSS. | HTML, Tailwind CSS |
| [Profile Card](./Profile%20Card/) | A styled profile card with a photo and profile details. | HTML, CSS |
| [Restaurant Landing Page](./Restaurant%20Landing%20Page/) | A restaurant website landing page with food, brand, and contact sections. | HTML, CSS |
| [Snake Game](./SnakeGame/) | A Snake game drawn on a canvas, with separate files for rendering, input, and game logic. | HTML, CSS, JavaScript |
| [UltraEdit Clone](./UltraEdit%20Clone/) | A practice recreation of the UltraEdit website landing page. | HTML, CSS |

## Run the Projects

For the static HTML and CSS projects, open the project's `index.html` file in a browser.

To run the Tailwind CSS watcher for the e-commerce homepage:

```bash
cd "E-commerce website /Home Page"
npm install
npm run dev
```

Then open that folder's `index.html` in a browser.

## Learning Goals

- Practice building and styling web pages with HTML and CSS.
- Learn to use Tailwind CSS in a project.
- Build interactive browser experiences with JavaScript and canvas.
- Continue toward full-stack development by learning APIs, servers, and databases.
